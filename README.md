# CodeAlpha EDA - Netflix Dataset

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The objective of this project is to perform Exploratory Data Analysis (EDA) on a Netflix dataset to identify patterns, trends, and insights from the available data.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset

The dataset contains information about Netflix titles, including:

- Title
- Rating
- Rating Level
- Rating Description
- Release Year
- User Rating Score
- User Rating Size

## Data Cleaning

The dataset was analyzed for:

- Missing values
- Duplicate records
- Data types

Missing values were handled, and duplicate records were removed before performing the analysis.

## Exploratory Data Analysis

The analysis explored:

- Distribution of content ratings
- Netflix titles across release years
- Most common content ratings
- Relationship between release year and user rating score
- Average, highest, and lowest user rating scores
- Top-rated titles

## Files

- `CodeAlpha_EDA_Netflix.ipynb` — Complete EDA notebook
- `CodeAlpha_EDA_Netflix.py` — Python source code
- `netflix.csv` — Dataset used for analysis
